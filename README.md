# Rockit — Lost in Forwarding · campaign media

Public media files for Rockit Transport Services & Logistics' "Lost in Forwarding" social campaign
(Instagram, Facebook, LinkedIn). Served via jsDelivr for the platforms' publishing APIs.

- `*_reel_9x16.mp4` — Reels (1080×1920, H.264)
- `*_story_9x16.jpg` — Stories and Reel covers (1080×1920)
- `*_feed_4x5.jpg` — feed images (1080×1350)

Brand sign-off (16 Nov 2026): every creative ends with the owner's logo (`brand/rockit-logo.png`) on a white strip,
replacing the earlier text wordmark on navy. Applied by `campaign_tools/apply_brand_strip.py` (strips rendered by
`campaign_tools/render_strips.js`); reels are processed frame by frame so the strip follows the band as it slides in.
